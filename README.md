# Выключаем ручной режим — интерактивный прототип

Прототип сайта специалиста по автоматизации бизнес-процессов с AI.
High concept: **«Выключаем ручной режим»** · «Из ручных процессов — в систему» · «Сначала процесс. Потом технология.»

Один самодостаточный файл: [`index.html`](index.html) — HTML, CSS и JS внутри, без сборки и зависимостей.
Внешний ресурс только один — шрифт Manrope с Google Fonts.

## Запуск

```bash
npx serve .
```

Или просто открыть `index.html` в браузере.

## Структура и интерактив

| # | Секция | Что делает |
|---|--------|-----------|
| 1 | Hero | только метафора перехода: переключатель `Ручной режим ⇄ Система`, схема из 5 шагов становится схемой из 4. Без метрик — это эмоциональный вход |
| 2 | Где у вас включён ручной режим | 6 карточек диагностики |
| 3 | Один процесс. Два способа работать | подробное before/after: схема в ряд, метрики 6/12/3 → 2/2/1, переход «Посчитать потенциал» к калькулятору |
| 4 | Калькулятор | название процесса, 3 слайдера, доля 25/50/75/90, пересчёт в реальном времени, progress ring, полоса из 20 сегментов с подвижной точкой |
| 5 | Несколько процессов | до 5 штук: добавить, изменить, свернуть/развернуть параметры, удалить. Общий потенциал считается с первого процесса |
| 6 | Ваш потенциал автоматизации | итоговая карточка: часы, процессы, рабочие дни, часы в неделю, месяцы, ручные действия. Поделиться / ссылка / PNG / показать специалисту |
| 7 | Что можно передать системе | 6 карточек от бизнес-задачи, инструмент — мелкой подписью |
| 8 | Методология 01–04 | подсветка этапов по скроллу |
| 9 | Как это может работать | 3 сценария с бейджем «Пример сценария» — не кейсы, цифр экономии нет |
| 10 | Social proof | плейсхолдеры логотипов |
| 11 | Обо мне | «Я не внедряю AI ради AI» |
| 12 | Финальный CTA | меняется: прошёл калькулятор → «У вас есть потенциал +N часов в год» |
| 13 | Форма | выбор канала связи, состояние «процесс принят в разбор» |

## Логика калькулятора

```
часов в неделю = сотрудники × раз в неделю (на сотрудника) × минут ÷ 60 × доля
часов в год    = часов в неделю × 52
часов в месяц  = часов в год ÷ 12
рабочих дней   = часов в год ÷ 8
месяцев работы = часов в год ÷ (8 × 21)
ручных действий в неделю = сотрудники × раз в неделю × доля
```

Все цифры считаются из этих формул — зашитых «красивых» чисел нет.
Старт: 3 сотрудника × 20 раз × 12 минут × 50% → **+312 часов в год**, и этот процесс сразу входит в общий итог.

Округление: годовые и месячные значения — до целых; значения меньше 10 — с одним знаком (5,5 часа). Ложной точности вроде `286,37` нет.

## Ссылка на результат

Кнопка «Скопировать ссылку» собирает адрес вида `?r=<состояние>#calc`.
Состояние — base64url от массива `[[название, сотрудники, раз, минут, доля], ...]`.

Открывший ссылку видит тот же расчёт, баннер «Этим расчётом с вами поделились» и кнопку «Посчитать свой процесс» — это viral loop.
Параметры из ссылки валидируются и зажимаются в допустимые диапазоны; битая ссылка просто открывает обычный расчёт.

## Карточка результата

«Сохранить карточку» рисует на canvas изображение 1080 × 1350 (графит, синий акцент, лаймовая точка) и открывает его в оверлее: «Скачать PNG» либо сохранение долгим нажатием на телефоне.
«Поделиться результатом» вызывает Web Share API, где он есть; иначе копирует текст со ссылкой в буфер.

## Что в прототипе — плейсхолдер

- **Логотип** — `[BRAND MARK]`, знак не перерисовывался и не генерируется кодом.
- **Фото** — `[Фото]`, логотипы клиентов — `[Логотип]`.
- **Сценарии** в блоке «Как это может работать» — гипотетические, помечены бейджем. Цифры экономии не выдуманы: их там нет.
- Показатели вроде «100+ проектов» не выводятся, пока не подтверждены.
- Форма ничего не отправляет: показывает состояние «процесс принят в разбор».
